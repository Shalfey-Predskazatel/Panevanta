# Сборка Panevanta 0.7

В папке Source находятся приложение и нативный движок. В публичном Git-репозитории нет офлайн-кэша инструментов и файлов NVIDIA SDK из комплекта восстановления.

## Требуемые компоненты

- Windows x64.
- .NET SDK 8.0.428.
- MSYS2 CLANG64 с clang и clang++.
- Заголовки CUDA 12.
- Файлы NVIDIA Video Effects SDK, необходимые движку, полученные и используемые по соответствующей лицензии NVIDIA.
- NuGet-пакеты проекта.

Скрипт Build-Panevanta.ps1 ожидает такие папки рядом с Source:

    Dependencies/Build/
    Dependencies/NVIDIA-VideoFX/
    Source/

Скрипт распакует .NET SDK, MSYS2 и заголовки CUDA в отдельную рабочую папку, соберёт автономное приложение и скомпилирует Panevanta.Native.dll. Запускайте его из корня полного комплекта восстановления:

    ./Source/Build-Panevanta.ps1 -WorkDirectory C:/temp/Panevanta-Rebuild

Рабочая папка должна находиться вне комплекта восстановления. Для запуска VFG рядом с собранной папкой Program нужна лицензированная папка Dependencies/NVIDIA-VideoFX. В portable ZIP релиза включены файлы среды выполнения и уведомления о лицензиях.

В публичном репозитории архив зависимостей намеренно отсутствует. Без него скрипт офлайн-сборки не запустится. Не распространяйте файлы SDK, если лицензия этого не разрешает.
