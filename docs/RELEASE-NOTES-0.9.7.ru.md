# Panevanta 0.9.7

[English](RELEASE-NOTES-0.9.7.md) · **Русский**

Panevanta 0.9.7 — portable-релиз для Windows x64, который применяет эффекты NVIDIA RTX к выбранному окну или экрану.

## Основные изменения

- Добавлен DLSS 5 Neural Rendering с выбором стиля, разрешения обработки, числа проходов и режима улучшения лиц и текстур.
- Добавлен режим стримера с отдельным изменяемым окном вывода для захвата в OBS.
- Добавлены автоматическая оценка частоты источника, автоматический множитель генерации кадров и автоподбор профиля по замерам текущей сцены.
- Добавлены компактные элементы управления, команды в системном трее и сохранение настроек. VFG, RTX Video Super Resolution, HDR и DLSS 5 NR можно менять во время работы.
- В исходный архив включены актуальное приложение на Rust и Tauri, интерфейс React, нативный GPU-движок и документация по исходникам и сборке.

## Скачать и запустить

Скачайте `Panevanta-0.9.7-Portable-win-x64.zip`, распакуйте архив целиком и запустите `Program/Panevanta.exe`. Комбинация для запуска захвата по умолчанию — **Shift + Alt + S**. В portable-архив также входят уведомления о сторонних компонентах и русская краткая инструкция.

Для эффектов NVIDIA нужна совместимая видеокарта RTX и драйвер GeForce. Результат зависит от источника, режима дисплея, драйвера и выбранных эффектов. В архив включён русский QA-документ с описанием проверок релиза и их ограничений.

## Файлы

- `Panevanta-0.9.7-Portable-win-x64.zip` — portable-приложение для Windows x64.
- `Panevanta-0.9.7-Source.zip` — исходный код и документация.
- Файлы `.sha256` — контрольные суммы SHA-256 для обоих архивов.

Оригинальный код Panevanta и скрипты сборки распространяются по лицензии MIT. На NVIDIA SDK, модели, runtime и другие сторонние компоненты распространяются их собственные условия. Подробности см. в уведомлениях исходного архива.
