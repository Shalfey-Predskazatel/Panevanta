# Panevanta 0.7 source publication

This update adds the C# application source, native engine, build scripts, application icon, and bilingual source documentation to the repository.

The existing Panevanta 0.7 portable binary is unchanged. The 3.1 GB offline toolchain and SDK cache is not included. A source-only archive is attached to the existing v0.7 GitHub release.

The source bundle does not include user settings, logs, or personal configuration. Functional tests were not run as part of this source publication.
