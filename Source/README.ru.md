# Исходники Panevanta

[English](README.md) · **Русский**

В репозитории собраны исходные материалы Panevanta 0.9.7 и компоненты предыдущих версий.

- `Rust/` — текущее приложение для Windows на Rust, Tauri и React.
- `Native/` — движок Direct3D 11, CUDA и NVIDIA Video Effects, используемый текущим приложением.
- `Panevanta/` — исходники предыдущей managed-версии приложения.
- `Interop/` — отдельный эксперимент по interop, не входящий в portable-релиз 0.9.7.

Инструкция по текущему приложению доступна на [английском](Rust/README.md) и в [подробном руководстве на русском](Rust/README.ru.md). В архив исходников не включены полный офлайн-комплект инструментов и все файлы NVIDIA SDK. Перед получением или распространением сторонних компонентов проверьте их лицензии.
