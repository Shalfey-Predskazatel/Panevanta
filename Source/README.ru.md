# Исходный код Panevanta

[English](README.md) · **Русский**

В этой папке находятся приложение Panevanta 0.7.0 на C#, нативный движок D3D11/CUDA, отдельный interop-пример, скрипт сборки и ресурсы.

- Panevanta: настольное приложение для Windows.
- Native: движок D3D11, CUDA, RTX Video и вывода изображения.
- Interop: отдельный эксперимент с D3D12/CUDA, который не используется в опубликованной программе.
- Build-Panevanta.ps1: сборка из полного комплекта восстановления с необходимыми папками зависимостей.

В публичном репозитории нет офлайн-архива инструментов и файлов NVIDIA SDK. Перед пересборкой прочитайте [инструкцию по сборке](../docs/building.ru.md).
