# Исходники Panevanta 0.9.7

[English](README.md) · **Русский**

`src/` — приложение Rust. `frontend/` — React, Tailwind CSS, Tauri API и локальные компоненты shadcn/ui. Vite записывает сборку интерфейса в `ui/`, откуда её встраивает Tauri.

- `main.rs` — команды интерфейса, глобальная клавиша, сохранение настроек и окно Tauri.
- `win.rs` — список окон и мониторов, параметры дисплея и прозрачный для ввода слой вывода.
- `preview.rs` — отдельное окно стримера и подгонка обработанного кадра под его клиентскую область.
- `capture.rs` — Windows Graphics Capture, очередь последнего кадра, жизненный цикл сеанса и телеметрия.
- `cadence.rs` — замер частоты по изменениям изображения и расчёт множителя.
- `engine.rs` — привязка ABI к прежнему GPU-движку Direct3D 11, CUDA и NVIDIA Video Effects SDK. Реализация движка в `../Native`.
- `sound.rs` — синтез коротких звуков действий и событий захвата. Звуки и визуальные эффекты управляются раздельно. [Визуальная система](DESIGN.md)
- `nr.rs` и `../Native/DlssNr.cpp` — проход DLSS 5 NR через публичный загрузчик NGX и отдельное устройство D3D12. Цветовые текстуры передаются на той же видеокарте. Нативная библиотека формирует коррекцию в выбранном разрешении и смешивает её с кадром захвата перед VFG, SR и HDR.

## Сборка приложения

Понадобятся Rust для `x86_64-pc-windows-msvc`, MSVC Build Tools с Windows SDK и Node.js 22.12 либо новее. Запускайте команды из x64 Native Tools Command Prompt или Developer PowerShell с настроенным MSVC.

В материалах разработки 0.8 указана конфигурация Cargo 1.99.1, Node.js 26.13.0 и Visual Studio Build Tools 17.14.45. Версии библиотек зафиксированы в `Cargo.lock` и `frontend/package-lock.json`. В проверенной портативной папке лежит резервный WebView2 Fixed Version 158.0.4370.45 для x64.

```powershell
cd Source/Rust/frontend
npm ci
npm run build
cd ..
cargo build --release --locked --target x86_64-pc-windows-msvc
```

Для готовой папки передайте путь к распакованной портативной 0.7, где лежат исходная версия нативной DLL и лицензированные зависимости NVIDIA.

```powershell
cd Source/Rust
.\Build-Portable.ps1 -Baseline 'D:\Panevanta-0.7-Portable-win-x64\Panevanta-0.7-Portable' -OutputDirectory 'D:\Panevanta-0.8-Portable'
```

При изменениях в GPU-движке `Build-Native.ps1` собирает новую DLL из `../Native` с MSYS2 CLANG64, заголовками CUDA и NVIDIA Video Effects SDK. Передайте её в `Build-Portable.ps1 -NativeDll <путь>`. Точный набор инструментов 0.7 и лицензии SDK перечислены в документации репозитория.

Для резервного офлайн-запуска добавьте `-FixedWebView2 <папка>` с распакованным официальным WebView2 Fixed Version для x64. При наличии системного WebView2 приложение использует системную копию, которая обновляется Windows.

Для сборки прохода NR выполните `Build-Nr.ps1 -SdkRoot <NVIDIA DLSS SDK 310.9.16> -OutputDirectory <папка>` в x64 Developer PowerShell. Передайте полученную DLL как `-NrBridge` и исходную лицензию SDK как `-NrSdkLicense` в `Build-Portable.ps1`. Для комплекта с моделью добавьте `-NrRuntime <путь к nvngx_dlssnr.dll>`. Скрипт проверит подпись NVIDIA и скопирует библиотеку в `Dependencies/DLSS-NR`.

## Поведение захвата

Окна обрабатываются по поступлению кадров. Для монитора Rust использует таймер захвата и берёт самый свежий доступный кадр. Авто-FPS анализирует небольшую центральную область, игнорирует период сразу после движения курсора и фиксирует частоту после двух согласованных измерений. Для статичного изображения или непредсказуемой частоты можно выбрать входной FPS вручную.

При смене параметров VFG, SR, HDR или основного разрешения обработки текущая очередь GPU пересоздаётся. Параметры DLSS 5 NR подаются в действующий проход, а изменение разрешения NR перестраивает только ресурсы и модель этого прохода. Его инициализация выполняется на отдельном потоке. В режиме захвата окна слой вывода скрывается, когда фокус у другого приложения.

Режим стримера передаёт кадры в отдельное окно Win32. Идентификатор этого окна сохраняется до остановки сеанса, в том числе при пересоздании GPU-очереди. Настройки хранятся в `Program/settings/panevanta.json`. Окно-источник восстанавливается по имени, исполняемому файлу и классу Win32, поскольку системный дескриптор окна меняется при повторном запуске.

Для быстрого управления создаётся отдельное окно Tauri `compact`. У окна есть нативная защита от активации и исключение из Windows Graphics Capture. Перетаскивание использует положение системного курсора и `SetWindowPos` с флагом `SWP_NOACTIVATE`. Полное и компактное окна используют одни настройки и один сеанс обработки.

Автоподбор в `frontend/src/lib/tuning.js` запускает временные профили через обычный движок и сравнивает измерения вывода. Проверки алгоритма запускаются командой `node --test test/tuning.test.js` из папки `frontend`.
