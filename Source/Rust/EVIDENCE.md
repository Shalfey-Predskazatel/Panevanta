# Подтверждение поведения интерфейса

| Что показывает приложение | Откуда это берётся |
| --- | --- |
| Список источников | Win32, окна и мониторы текущей сессии |
| Целевая частота в блоке сеанса | Входная частота × множитель VFG. Для Auto учитывается текущая частота дисплея |
| Захват, вывод и возраст кадра | Счётчики Windows Graphics Capture, нативный журнал DXGI и QPC |
| HDR в строке обработки | Подтверждённое цветовое пространство HDR10 нативного движка |
| Светлая и тёмная тема, меню и фокус | Тест нативного окна WebView2 и снимки приложения |
| Звуки действий | Синтез PCM в Rust и результат вызова WinMM, настройки Windows управляют фактической громкостью |

Измерения и стенд описаны в [протоколе 0.8](../../docs/qa-0.8.ru.md).
